y-lab-google-api

個人用の小さなツールです。開発者本人のパソコンで動くスクリプトから、本人の Google ToDo リスト（Google Tasks）にタスクを追加・表示します。

This is a personal tool. Scripts running on the developer's own computer add and list tasks in the developer's own Google Tasks.

  • 利用者は開発者本人だけです / Used only by the developer.
  • 使う権限: Google Tasks の読み書き（https://www.googleapis.com/auth/tasks）
