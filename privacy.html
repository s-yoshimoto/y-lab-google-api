プライバシーポリシー / Privacy Policy

最終更新 / Last updated: 2026-10-31

対象

このポリシーは、個人用ツール「y-lab-google-api」に適用されます。このツールの利用者は開発者本人だけです。

アクセスするデータ

Google Tasks API（スコープ https://www.googleapis.com/auth/tasks）を通じて、利用者自身の Google ToDo リストのタスクリストとタスクを読み書きします。それ以外の Google のデータにはアクセスしません。

データの使い方と保存

  • データは、利用者のタスクを追加・表示するためだけに使います。
  • 認証トークンは利用者のパソコンの中だけに保存し、外部のサーバーには送りません。
  • データを第三者に販売・提供・共有することはありません。広告にも使いません。

Google API サービスのユーザーデータに関するポリシー

このツールが Google API から受け取った情報の利用と他のアプリへの転送は、限定的使用の要件を含む Google API サービスのユーザーデータに関するポリシー に従います。

アクセスの取り消し

Google アカウントのサードパーティ アクセス から、いつでもこのツールのアクセスを取り消せます。

English summary

y-lab-google-api is a personal tool used only by its developer. It accesses only the user's own Google Tasks (scope https://www.googleapis.com/auth/tasks) to add and list tasks. Tokens are stored only on the user's own computer. No data is sold, shared with third parties, or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
